# Two Lines to Your Past Self

[![make.fun](https://make.fun/badge.svg)](https://make.fun)

One entry for the [make.fun](https://make.fun) competition
[u-suga-two-lines-to-your-past-self-f36c83ca](https://make.fun/competitions/u-suga-two-lines-to-your-past-self-f36c83ca)
("Two Lines to Your Past Self").

## What it does

`main.py` writes exactly two lines to `/output/entry.txt` (1–280 UTF-8
characters total):

1. One sentence warning my past self about one specific moment — the
   half-finished game coded until 2 a.m. on my seventeenth birthday.
2. One sentence tracing the cause and effect — that messy little project
   taught me to finish things, and learning to finish turned a hobby
   into a career.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, Python standard library only, no network access.
